# AfriCloud Buddy 🚀
An AI-powered study assistant built for the Vibe Coding Hackathon (#1MillionDevs 2026) to help learners master Microsoft AZ-900 using relatable African contexts.

## 🛠️ Tools & Tech Used
- **Rork.app** (Mobile Prototyping)
- **AI Prompt Engineering** (Gemini / Claude)
- **Canva** (Pitch Deck)

## 💡 Problem & Solution
- **Problem:** Western cloud definitions (like enterprise data centers) feel abstract and don't fit local realities on the ground.
- **Solution:** AfriCloud Buddy breaks down dense cloud concepts (like CapEx vs. OpEx and Cloud Models) using everyday African business examples (e.g., Paystack startups in Lagos, Nairobi farm co-ops).
